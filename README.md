# gamee
1. Общие сведения о проектеПрограмма представляет собой графическую кроссплатформенную реализацию классической головоломки «2048», выполненную в космической стилистике.Язык программирования: C++ (совместим со стандартами от C++11 до C++20).Графический движок: Raylib (работает на аппаратном ускорении OpenGL).Режим отображения: Эксклюзивный полный экран (Fullscreen) с автоматической адаптацией интерфейса под любое разрешение монитора.2. Архитектура данных (Структуры)struct TileОписывает одну ячейку (плитку) на игровом поле. Поддерживает динамическое изменение состояния для отрисовки плавных анимаций.int value — текущее числовое значение на плитке (2, 4, 8 и т.д.). 0 означает пустую ячейку.int prevValue — значение плитки на предыдущем ходу (используется для контроля изменений).Vector2 currentPos — текущие экранные координаты (X, Y) плитки во время анимации перемещения.Vector2 targetPos — целевые экранные координаты (X, Y), куда плитка должна прийти в конце хода.float scale — коэффициент масштаба плитки (от 0.0f до 1.0f). Отвечает за плавное «вырастание» новой плитки из центра.bool isMoving — флаг, указывающий, что плитка в данный момент находится в процессе анимации скольжения.bool justMerged — флаг слияния. Активируется, когда плитка поглотила другую, для вызова спецэффектов.struct ButtonОписывает интерактивный элемент интерфейса (кнопку).Rectangle rect — геометрия кнопки на экране (позиция X, Y, ширина, высота).string text — отображаемый текст.bool isHovered — флаг наведения курсора мыши (меняет цвет кнопки).struct StarОписывает элемент заднего фона (звезду).Vector2 position — координаты звезды.float radius — радиус (размер).float maxAlpha — максимальная яркость (прозрачность).float currentAlpha — текущая яркость для математического расчета мерцания.float glowSpeed — скорость изменения яркости.struct SparkОписывает единичную частицу (искру) эффекта взрыва при слиянии чисел.Vector2 position / Vector2 speed — позиция и вектор скорости разлета.Color color — цвет искры (динамически наследует цвет созданной плитки).float radius / float alpha — размер и прозрачность.float life — оставшееся время жизни частицы в секундах.3. Математические и графические особенности кода3.1. Оптимизированный алгоритм WASD (GetLinePointers)Вместо написания четырех громоздких функций сдвига для каждого направления (Вверх, Вниз, Влево, Вправо), в коде применен метод индексации указателей. Функция SlideLine умеет двигать ряды только в одном направлении. Функция GetLinePointers перед каждым ходом динамически переназначает массив указателей activeLine[SIZE] на реальные строки или столбцы матрицы board в зависимости от нажатой клавиши. Это сократило объем логического кода в 4 раза.3.2. Трехмерный процедурный рельеф ЛуныЛуна генерируется математически на каждом кадре без использования тяжелых внешних картинок:Атмосферное свечение (Bloom): Используется аддитивный режим смешивания цветов BeginBlendMode(BLEND_ADDITIVE). Накладывается 35 слоев кругов с затухающей прозрачностью, чья яркость привязана к синусоиде времени sinf(time). Это создает эффект мягкой «живой» пульсации неонового света.Объемные кратеры (Chiaroscuro): Каждый кратер состоит из трех слоев: белой солнечной каймы (сдвинутой к свету), базового дна и глубокой тени (сдвинутой от света). Это создает обман зрения и сильный 3D-эффект.Градиентный Терминатор: На правую сторону луны накладывается 40 тончайших слоев полусфер тени DrawCircleSector. Тень плавно сгущается к краю, создавая идеальный эффект шарообразности.3.3. Физика сглаживания движения (Интерполяция)В функции UpdateAnimation шаг сдвига рассчитывается на основе дельты времени GetFrameTime() (step = SPEED * dt). Это гарантирует, что на любом мониторе (60 Гц, 144 Гц, 240 Гц) плитки будут скользить с абсолютно одинаковой скоростью и без рывков. Скорость сдвига установлена на агрессивные 2400.0f пикселей в секунду для мгновенного отклика.4. Спецификация ключевых функцийRestartGame() — полностью очищает поле, обнуляет текущий счет, системы частиц и создает две стартовые плитки.MakeMove(int key) — основной мозг игры. Принимает нажатую клавишу, делает бэкап поля, вызывает сдвиг, проверяет, изменилось ли поле. Если поле изменилось, возвращает true (что дает сигнал на спавн новой плитки).IsGameOver() — сканирует поле. Если пустых мест (value == 0) нет и ни по горизонтали, ни по вертикали нет одинаковых соседних чисел, фиксирует проигрыш.CreateSparksExplosion(Vector2 centerPos, Color tileColor) — генерирует 15 искр, которые вылетают под случайными углами (rand() % 360) из центра объединившихся плиток.LoadHighScore() / SaveHighScore() — функции работы с файловой системой. Сохраняют лучший результат в файл highscore.txt в папке с игрой. Данные не сбрасываются после закрытия приложения.5. Решение проблем компиляции (MSVC / Visual Studio)В самом начале кода прописаны директивы, устраняющие главные системные баги при сборке графических проектов:#pragma comment(linker, "/SUBSYSTEM:CONSOLE") — принудительно указывает Visual Studio открывать стандартный поток ввода/вывода, защищая от конфликтов типов окон Windows.#pragma comment(linker, "/ENTRY:mainCRTStartup") — жестко задает точку входа, избавляя от известной ошибки линкера «неразрешенный внешний символ main в функции invoke_main».#pragma comment(linker, "/NODEFAULTLIB:MSVCRT") — отключает конфликт статических (/MT) библиотек сборки самого Raylib и динамических настроек текущего проекта Visual Studio.6. Руководство оператора (Управление в игре)Передвижение плиток: Классические стрелки клавиатуры или клавиши W (вверх), A (влево), S (вниз), D (вправо).Перезапуск: Клик левой кнопкой мыши по интерактивной кнопке RESTART в верхней части экрана. Кнопка имеет эффект Hover (подсвечивается при наведении).Выход: Клавиша ESC (мгновенно закрывает игру и сохраняет рекорд).
